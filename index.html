Über dieses Grimoire
Handschrift-Notizbuch im D&D-Papier-Stil: Stift, Marker, Radierer, Textboxen (mit dem Texteditor aus dem DND-Repo), Bilder, Seiten, Thumbnails. Mehrere Dokumente in der Bibliothek, Einzel- und Gesamt-Export als JSON, GoodNotes-Import (.goodnotes) inkl. Handschrift. Alles wird lokal im Browser gespeichert – kein Server, offline-fähig (PWA). ☁ WEBDAV-SYNC
Funktioniert komplett im Browser per fetch() (PUT/GET/PROPFIND) – kein eigener Server nötig. Für Nextcloud ein App-Passwort nutzen (Profil → Sicherheit → App-Passwörter). Server-URL z. B. https://cloud.example.de/remote.php/dav/files/USERNAME.
CORS-Hinweis: Der Server muss deine Grimoire-URL erlauben. Fehler mit „Failed to fetch“ / CORS → Grimoire auf dieselbe Domain legen (z. B. Nextcloud-Ordner hosten), Reverse-Proxy mit Access-Control-Allow-Origin nutzen, oder weiter manuell per ⬇/⬆ JSON arbeiten. Alternative ohne CORS: Nextcloud-Desktop-Client + Browser-Ordner syncen.
