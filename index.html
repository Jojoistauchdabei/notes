Über Federwerk
Handschrift-Notizbuch im Papier-Stil: Stift, Marker, Radierer, Textboxen mit Rich-Text-Editor, Bilder, Seiten, Thumbnails. Mehrere Dokumente in der Bibliothek, Einzel- und Gesamt-Export als JSON, GoodNotes-Import (.goodnotes) inkl. Handschrift. Alles wird lokal im Browser gespeichert – kein Server, offline-fähig (PWA). Optional: ☁ WebDAV-Sync (z. B. Nextcloud), komplett im Browser – siehe ☁⚙.

☁ WEBDAV-SYNC
Funktioniert komplett im Browser per fetch() (PUT/GET/PROPFIND) – kein eigener Server nötig. Für Nextcloud ein App-Passwort nutzen (Profil → Sicherheit → App-Passwörter). Server-URL z. B. https://cloud.example.de/remote.php/dav/files/USERNAME.
CORS-Hinweis: Der Server muss deine Federwerk-URL erlauben. Fehler mit „Failed to fetch“ / CORS → Federwerk auf dieselbe Domain legen (z. B. Nextcloud-Ordner hosten), Reverse-Proxy mit Access-Control-Allow-Origin nutzen, oder weiter manuell per ⬇/⬆ JSON arbeiten. Alternative ohne CORS: Nextcloud-Desktop-Client + Browser-Ordner syncen.
