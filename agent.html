KI-Agent & MCP

← Zur App

Lass eine KI in deinen Notizen arbeiten – wie eine zusätzliche Hand, die tippt, sortiert und lernt.

Was steckt dahinter

Federwerk spricht das Model Context Protocol (MCP). Damit kann eine KI (Claude, Cursor, Opencode, …) deine Notizen lesen und schreiben: Notizen anlegen und bearbeiten, Ordner verwalten, Karteikarten-Decks anlegen und bewerten, Volltext- und Tag-Suche, Wikilink-Graph.

📄 Anleitung fürs KI-Modell 📚 Doku für Techniker

/mcp liefert eine Markdown-Datei, die jedem KI-Modell erklärt, wie es den MCP installiert, anmeldet und benutzt. Du kannst die Adresse einfach in deinen Chat kopieren: Bitte lies /mcp und richte den Federwerk-MCP ein.

① Einloggen (einmalig)

Der Server meldet sich mit deinen Zugangsdaten selbst an – du brauchst keinen API-Key. Der Ordner liegt im Home-Verzeichnis und ist nur für dich lesbar.

cd /pfad/zu/notes
node mcpserver/login.js --email deine@adresse.de --save

Das Passwort wird interaktiv abgefragt (nicht in der Terminal-History gespeichert) und nach ~/.config/federwerk/mcp-credentials.json (chmod 600) geschrieben. Abmelden: node mcpserver/login.js --logout.

② Mit deiner KI verbinden

Trage den Server in deinen KI-Client ein (Claude Desktop, Cursor, Opencode …):

{
  "mcpServers": {
    "federwerk": {
      "command": "node",
      "args": ["/pfad/zu/notes/mcpserver/cli.js"]
    }
  }
}

Danach den Client neu starten. Beim Start meldet der Server auf stderr, ob er wirklich mit deiner Cloud verbunden ist:

Federwerk MCP: Cloud-Backend als Nutzer <deine-ID> (angemeldet).

Steht dort „Demo-Backend (flüchtig)", fehlen die Anmeldedaten – Schritt ① wiederholen. Sonst arbeitet die KI nur in einer flüchtigen Demo, nicht in deinen Notizen.

③ Was die KI für dich tun kann

📝 Notizen

Anlegen, Text anhängen statt überschreiben, umbenennen, kopieren, in Ordner verschieben, löschen (mit Sicherheitsstufe).

🗂 Ordner

Anlegen, umbenennen, löschen – enthaltene Notizen werden nicht verloren, sondern wandern mit.

🎴 Karteikarten

Decks aus Notizen bauen, Karten pflegen und nach dem SM-2-System bewerten – exakt wie in der App.

🔍 Suche & Graph

Wortsuche, Tag-/Aufgaben-Suche (tag:reise, task-todo:steuer) und Wikilink-Netz aus [[…]]-Verweisen.

Beispiele – so kannst du es anfragen

  • „Leg eine Notiz Steuer 2027 an mit einer Checkliste: Anmeldung bis 31.03., Erste Rate, Reisekosten."
  • „Mach aus meinen Deutsch-Vokabeln ein Karteikarten-Deck."
  • „Zeig mir alle offenen Aufgaben in meinen Notizen."
  • „Fasse die Notizen zu Berlin in einem neuen Dokument zusammen und verlinke sie mit [[Hauptprojekt]]."
  • „Verschiebe alle Notizen mit #reise in den Ordner Reisen."

⚠️ Wichtig

  • Die KI sieht genau deine Notizen – behandle sie wie einen Gesprächspartner mit Zugriff auf dein Tagebuch. Teile keine Zugangsdaten im Chat.
  • Passwörter gehören nicht in Tool-Aufrufe. Bitte deine KI, das login-Werkzeug zu nutzen – es liest die Daten aus dem geschützten Speicher.
  • Appwrite erlaubt pro Konto nur eine begrenzte Zahl Sitzungen und meldet dabei die ältesten ab. Viele gleichzeitig laufende KI-Instanzen können deine App abmelden – die Notizen bleiben aber erhalten, du meldest dich einfach neu an.
  • Gelöscht wird zweistufig: erst „in den Papierkorb" (bleibt für den Sync nachvollziehbar), endgültig nur auf ausdrücklichen Wunsch.
